## How to run

1. Unzip `Sepsis_data.zip` to get `Patients.csv` and `Genes.csv`.
2. Open `Sepsis_BT3041.ipynb` in Google Colab or Jupyter.
3. Upload `Patients.csv` and `Genes.csv` to the notebook's working directory.
4. Run all cells.
